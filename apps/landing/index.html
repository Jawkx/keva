One list.
Everything in it.

No folder trees to build, no paths to remember. Every file lands in one sortable list — then you narrow it down the moment you need something. Save any filter as a view and it lives in your sidebar.

What Keva does

Preview

See what's inside, instantly.

PDFs, images, spreadsheets, text and code open right where they are. No download step, no other app.

Share

Share a link, not a folder.

Any file — or any filtered view of them — becomes a link. Pick the access, set an expiry, revoke it whenever you like.

Collect

Let others send you files.

Turn on upload access and anyone with the link can drop files straight in. They arrive tagged the way you asked — and guests never see anything else.

Tags · metadata · properties

Organize by meaning,
not by location.

Put anything on a file: a bare tag, a value, a number, a flag. Then filter on it — and keep the filter if it's one you'll want again.
