For people, applications & agents

Hand it to an agent.

Keva speaks MCP, so an assistant can search, tag, and organise your objects the same way you do — from Claude, Cursor, or any MCP client.

keva · assistant MCP connected

Find last quarter’s invoices that aren’t marked paid, and tag them for review.

keva.search done 
{ type: "invoice", status: { not: "paid" }, period: "Q1-2026" }
→ 3 objects
  • PDF mar-invoice.pdf $4,200
  • PDF feb-invoice.pdf $1,980
  • PDF jan-invoice.pdf $3,510
keva.tag done 
{ items: 3, set: { review: true } }
→ tagged 3 objects · review = true

Done — the 3 unpaid invoices from last quarter are now tagged review = true. Want me to share them with the finance view?
